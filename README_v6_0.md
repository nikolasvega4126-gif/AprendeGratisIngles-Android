# Aprende Gratis Inglés V6.0

V6 parte de la V5.2 y conserva la ruta, práctica, pronunciación interna, exámenes, XP, racha, ligas locales, favoritos, contenido Blogger, modo sin conexión, vocabulario con repetición espaciada, conversaciones, calendario y copia/restauración.

## Novedades V6

- Tarjeta “Continúa donde quedaste” para abrir directamente la siguiente lección.
- Coach diario con 3 misiones: completar una lección, terminar una práctica y superar una frase de pronunciación con 70% o más.
- Bonus diario de +40 XP al completar las tres misiones.
- Práctica rápida de 5 preguntas además de la sesión completa.
- Progreso semanal con XP de los últimos 7 días en Logros y Perfil.
- Registro diario de XP para estadísticas reales desde la instalación de V6.
- Compatibilidad actualizada a Android API 36 (`compileSdk` y `targetSdk`) con Android Gradle Plugin 8.12.2 y Gradle 8.13.
- `versionCode 11` y `versionName 6.0`.

## Importante

La Liga XP sigue siendo local/simulada como en V5.2. No se presentan rivales simulados como usuarios reales. Para ranking real entre dispositivos hace falta un backend.

La compilación normal de GitHub Actions genera un APK debug para pruebas. Para publicar en Google Play se necesita un AAB release firmado con una clave de subida.
