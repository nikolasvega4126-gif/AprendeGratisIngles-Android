# Aprende gratis inglés - Android v2.0 dinámica

Aplicación Android conectada a https://www.aprendegratisingles.com/

## Novedades v2.0

- Inicio nativo dinámico.
- Las nuevas entradas de Blogger se cargan automáticamente desde el feed del sitio.
- Buscador de lecciones.
- Favoritos guardados en el dispositivo.
- Progreso y lecciones completadas.
- Botón "Continuar aprendiendo".
- Mini ejercicio de 10 preguntas.
- Audio TTS nativo de Android para la pronunciación.
- Caché del feed para seguir viendo la lista sin conexión.
- Lectura offline básica de las lecciones incluidas en el feed cacheado.
- Recordatorio diario de estudio a las 19:00.
- Icono oficial de Aprende gratis inglés.

## Compilación

El workflow `.github/workflows/build-apk.yml` genera `app-debug.apk` automáticamente en GitHub Actions.
