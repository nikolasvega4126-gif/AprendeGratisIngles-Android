# Aprende Gratis Inglés v5.2

Nueva experiencia de perfil y Liga XP.

- Conserva la intro animada existente.
- Primer acceso: crea un usuario local como @Joshuar.
- Avatar asignado automáticamente y modificable desde Perfil.
- Encabezado renovado: Nivel, Liga y progreso XP sustituyen el logo/nombre.
- Al tocar el bloque de nivel se abre la Liga XP.
- Ranking dinámico local que cambia con el XP del usuario.
- Perfil muestra usuario, avatar, liga, nivel y XP.
- Conserva ruta, práctica, logros, perfil, pronunciación interna, exámenes y progreso de v5.0.

Nota: la Liga XP de esta versión es local. Para mostrar usuarios reales de distintos teléfonos hace falta un backend/sincronización.
