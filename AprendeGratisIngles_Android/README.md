# Aprende gratis inglés - Android

Aplicación Android ligera para https://www.aprendegratisingles.com/

## Funciones incluidas
- Inicio integrado con la web oficial.
- Accesos rápidos a Lecciones, Pronunciación y Guías PDF.
- Navegación interna con botón Atrás de Android.
- Indicador de carga.
- Enlaces externos y descargas delegados al sistema.
- Sin permisos invasivos: solo INTERNET.

## Crear APK con GitHub Actions
1. Sube esta carpeta a un repositorio de GitHub.
2. Abre la pestaña Actions.
3. Ejecuta `Build Android APK`.
4. Descarga el artefacto `AprendeGratisIngles-debug-apk`.

El APK generado será `app-debug.apk` y sirve para instalar y probar en teléfonos Android.

## Para Google Play
Para publicar oficialmente se recomienda generar un Android App Bundle (.aab) firmado con una clave estable propia del propietario de la app.
